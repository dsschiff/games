# Games by Daniel Schiff

Public landing page for [Grovebound](https://dsschiff.github.io/grovebound/) and future games. Planetfall is represented as in development while its repository remains private.

GitHub Pages serves `main:/docs` at https://dsschiff.github.io/games/. The site is plain HTML and CSS with no build step. Art in `docs/art` comes from the public Grovebound repository.

## Game ideas

- [Mobile gameplay references](ideas/mobile-gameplay-references.md): Gear Defenders, Butcher Hero, Top Force, Kingshot, Last Human (Last Z-like), and Hero Wars. Build versions that deliver the advertised gameplay, or preserve the core gameplay when the ads represent it accurately.
