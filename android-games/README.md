# Personal Android games

Six standalone offline Godot games have software candidates ready for phone testing. The staged goal in the repository root remains open for physical and human acceptance. Reference briefs govern each implementation; commercial titles are design references.

| Directory | Working original title | Reference | Current state |
| --- | --- | --- | --- |
| `gear-bastion` | Gear Bastion | Gear Defenders | Private design update delivered; ready-phase Begin and native active-run retention verified; physical acceptance deferred |
| `tower-trials` | Tower Trials | Hero Wars | Private design update delivered; popup layout, save transactions and actual native earned-clear cold retention verified |
| `hook-and-hunger` | Hook and Hunger | Butcher Hero | Private design update delivered; hit/charge feedback and native active-run retention verified; phone IME gate explicit |
| `hearthguard` | Hearthguard | Kingshot | Private design update delivered; verified save transactions and native result/cold retention; physical acceptance deferred |
| `frontline-foundry` | Frontline Foundry | Top Force | Private design update delivered; recruit feedback and twelve-mission input campaign verified; physical acceptance deferred |
| `dead-run` | Dead Run | Last Human: Final Stand | Private design update delivered; terminal Retry, warning priority and crew clearance reviewed; native full-context retention verified |

Each app is offline and has independent saves. APKs and signing materials are local artifacts, excluded from Git. The existing public website is not changed by these builds.

See [current private releases](delivery.json) and [installation and phone checks](INSTALL.md) for all six current phone-test candidates.
