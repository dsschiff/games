# Personal Android games

Six standalone Godot games are being developed here under the staged goal in the repository root. Reference briefs govern each implementation. A commercial title is a design reference, not our app name.

| Directory | Working original title | Reference | Current state |
| --- | --- | --- | --- |
| `gear-bastion` | Gear Bastion | Gear Defenders | Reference research |
| `tower-trials` | Tower Trials | Hero Wars | Reference research |
| `hook-and-hunger` | Hook and Hunger | Butcher Hero | Reference research |
| `hearthguard` | Hearthguard | Kingshot | Reference research |
| `frontline-foundry` | Frontline Foundry | Top Force | Reference research |
| `dead-run` | Dead Run | Last Human: Final Stand | Reference research |

Each app is offline and has independent saves. APKs and signing materials are local artifacts, excluded from Git. The existing public website is not changed by these builds.
