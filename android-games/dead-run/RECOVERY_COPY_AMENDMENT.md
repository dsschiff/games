# Direct pending rescue-code copy controls

Known recovery owners previously offered View / Export actions without a direct complete-code copy button. Players had to select thousands of displayed characters manually. The existing scroll panel now has touch-sized **Copy Previous Code** and **Copy Imported Code** actions, backed directly by the helper’s retained validated original/imported strings. Neither TextEdit is the source. The original storage/uncertainty explanation remains unchanged; clipboard feedback is separate and scrolled into view after a tap.

The feature guard prevents clipboard calls on unsupported displays. Success text requires immediate exact complete-string clipboard readback; a mismatch reports unverified and an unsupported platform reports unavailable with the existing View fallback. Copy never writes an archive, journal or save slot, adopts a context, resolves the pending choice or resumes play. Deferred feedback reveal checks pending ownership, panel/label validity and visibility, so a resolved/closed panel is not reopened. An unavailable individual code disables its copy action. Unknown cold-marker recovery offers only Retry recovery read: copy actions, instructions and archive enumeration are absent.
