## Assessment

- **Compatible actors and reset:** Role is the actor key; Hearth roles determine their compatible authored model/rig. Mounted defender state is explicitly reset on every acquisition, including weapon bone scale, before tower scale/position are applied. Reset clears aim, gait, travel, recoil/hit/work/death, root transform, model transform and all bone poses. It restores health transforms/values and the WeaponTip marker, then synchronizes the actual attachment immediately. Preserving `model_rest` also retains the authored commander/swarm/boss scale through hydration. Same stable ID with a different role explicitly returns the old model and acquires the correct role. The fixture contaminates mounted pose, root/health/socket transforms, bone position/scale and death state, and compares the reused defender with a fresh one, including every bone and same-call socket.
- **Actual objects, not only resources:** The pool reparents live node instances to a hidden, disabled scene-owned branch; acquisition restores inherited processing, visibility and root identity. Corpse/contact retirement and tower operator rebuild actually use this path. Focused assertions verify reused actor identity and compatible projectile node/mesh/material identity. Existing fixed meshes/materials remain role-specific; no live actor code changes shared colors that would require a further palette reset.
- **Coin, label and effect reuse:** Keys separate coin models, value labels, projectiles and pulse rings. Each mutable effect mesh/material belongs to its node; changing a reused projectile family cannot recolor another active projectile. Return clears transform via the pool and resets mesh dimensions/radii and material color or label text/modulation. Acquisition sites assign the new position, geometry, color, text, orientation and fresh lifetime dictionary. Coin flight completes through the same reserve, while its label returns immediately. The fixture follows that actual path and verifies a new coin ID gets the same instances with the new value and no old spin/scale.
- **Bounded reserves and teardown:** Inactive actors are capped at four per role and 24 total; inactive effects at 16 per compatible kind and 64 total. These caps do not suppress active actors or authoritative feedback. Overflow is hidden/disabled immediately and queued for deletion; the fixture awaits a frame and verifies actual child counts, so queued overflow is not falsely counted as a permanent bounded reserve. Scene exit clears both reserve indexes; parent destruction owns the inactive branches and their children. The fixture retains external pool references and verifies both cleared indexes and actual node invalidation after teardown.
- **ID, epoch and Resume boundary:** Borrowed nodes hold no simulation ID or dedupe namespace. Active units/pickups and finite corpse/effect lists own those lifetimes. Adapter reset still advances epoch, copies snapshots and clears event history. Hydration retains only pending events stamped at the current first Resume tick when unheld, preserving the earlier boundary fix. Tests cover duplicate first-Resume shot, stale pre-boundary rejection, corpse-to-reused-ID hydration, stopped terminal gait and whole encoded save equality. The delta does not change the adapter, rules/RNG/save files, event damage timing or camera/input mapping.
