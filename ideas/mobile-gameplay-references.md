# Mobile gameplay references

Captured October 17, 2026.

Daniel wants playable versions inspired by these six mobile games: versions that match the advertised gameplay when the ads misrepresent the game, or versions of the core gameplay when the ads are accurate.

The chosen mechanic should remain the main activity throughout play, with enough levels, challenges, or progression to sustain it beyond a tutorial or occasional minigame. These are game ideas to develop, not a blanket finding that every reference uses misleading ads.

## The six games

| Reference | Gameplay direction for our version | What to establish before implementation |
| --- | --- | --- |
| **Gear Defenders** | Gear and unit placement, troop generation, and defense. Preserve the satisfying placement and battle loop if that is what the selected ad shows. | Compare the selected ad with sustained play; use the actual core loop if they match. |
| **Butcher Hero** | Hook enemies, pull them in, defeat them, absorb power, and grow stronger. | Compare the advertised hook-and-growth loop with actual play; retain the core mechanics if the ad represents them accurately. |
| **Top Force** | The military base and combat interaction shown in the selected ad. | Identify the exact advertised actions and how directly the player controls them before defining the version. |
| **Kingshot** | Active movement, building defenses, and surviving attacks, taking the action and defense presentation of its ads as the candidate main game. | Choose a specific ad as the reference. Distinguish its action and defense loop from the settlement and alliance systems. |
| **Last Human** | Zombie survival gameplay, with **Last Z** as Daniel's comparison. | Keep the name Last Human until the exact app is identified. Last Z is a comparison, not a seventh entry or a confirmed alternate title. Capture the particular ad before choosing its mechanics. |
| **Hero Wars** | A complete game built around the puzzle or action sequence in the selected ad. | Choose the particular ad and puzzle mechanic; compare it with the actual hero-team RPG before deciding which loop to preserve. |

The row order is not a priority ranking.

## Choosing the version

For each idea, retain a concrete ad clip or playable-ad recording and compare it with sustained gameplay. Write a short description of what the player repeatedly does, what makes the decisions interesting, and how the challenge develops.

- **If the ad differs from the main game:** make the advertised activity the main game, including when it exists only as a tutorial or small side mode in the reference.
- **If the ad accurately represents the main game:** preserve the appeal of that core gameplay.

Use original names, characters, art, and levels for our versions. The references identify mechanics and the experience Daniel wants.
